# DDTank36 — Windows 部署与扩展源码

本仓库保存 Windows x64 部署脚本、C# 扩展源码、服务配置及可编辑网页文件。完整运行资源和数据库种子随发行包提供，克隆本仓库后不能直接运行游戏。

## 运行依赖

本源码仓库不分发游戏本体、数据库种子和依赖安装程序。需要已有的完整 Windows x64 发行资源，克隆本仓库后不能直接开服。

将已有发行包完整解压后，按 [详细部署方法](详细部署方法.md) 操作。2026-11-03 中文脱敏发行包是本次源码整理的基线，不使用旧版完整修复包，也不重复纳入独立 MDF/LDF 数据库副本。

## 修改与编译

1. 先解压完整发行包，保留其 `package`、`prerequisites` 和数据库种子。
2. 将仓库内容覆盖到解压后的 `DDTank36` 目录。
3. 在 Windows 的 .NET Framework 4.8 环境执行 `Build-Extensions.ps1`；编译依赖发行包的服务器程序集和 Harmony。
4. 按部署说明运行部署脚本。
